# Algebra
Notes of 'Basic Algebra' by Zhang, Pu. I plan to add something about sheaf cohomology to this note later on.

The primary reference textbook is **"Lectures on Basic Algebra"**. I will try my best to avoid directly copying the book, but instead focus on organizing the logic and structure, fully detailing proofs that the book omits, as well as some important exercises, while only briefly outlining proofs that are already present in the text. I also hope to document more examples and counterexamples. My main goal in writing these notes is to compel myself to read those crucial, yet slightly obscure, proofs.
